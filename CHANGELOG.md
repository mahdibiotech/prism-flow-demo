# Changelog

## 0.1.0 — 2026-09-24

- Initial portfolio demonstrator.
- Metadata validation and patient/sample consistency checks.
- Synthetic end-to-end demo mode.
- Production paired-end FASTQ path using FastQC, Trim Galore, Salmon and tximport.
- Count-level QC and configurable QC gate.
- DESeq2 analysis with PCA and volcano plots.
- Quarto HTML reporting.
- Rule-level provenance and aggregated execution trace.
- SLURM profile template and CI tests.
